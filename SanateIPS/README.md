# SANATE I.P.S

## Proyecto

Aplicativo desarrollado en Java como Producto Mínimo Viable (PMV) para la gestión básica de pacientes de SANATE I.P.S.

El proyecto busca representar de manera sencilla algunas de las funciones que podría tener un sistema para apoyar los procesos de atención y recepción de pacientes.

## Funcionalidad principal

El aplicativo cuenta con un módulo de recepción desde el cual se puede acceder a la gestión de pacientes.

Actualmente se implementó un CRUD de pacientes que permite:

- Crear pacientes.
- Consultar pacientes por documento.
- Modificar la información de un paciente.
- Eliminar pacientes.

La información de los pacientes se maneja mediante clases Java y un servicio encargado de realizar las operaciones correspondientes.

## Tecnologías utilizadas

- Java
- Java Swing
- NetBeans
- Git
- GitHub

## Estructura básica

El proyecto está organizado de la siguiente manera:

- `modelo`: contiene las clases que representan los datos.
- `service`: contiene la lógica para gestionar los pacientes.
- `vistas`: contiene las interfaces gráficas desarrolladas con Java Swing.

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir el proyecto en NetBeans.
3. Ejecutar el proyecto desde la clase principal.
4. Ingresar al módulo de recepción.
5. Acceder a la gestión de pacientes para realizar las operaciones del CRUD.
